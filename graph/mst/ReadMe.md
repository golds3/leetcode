# 最小生成树

特点
1.在有权图中，求最小路径
2.有prim和kruskal两种方案

prim：
1.以节点为角度，复杂度固定为 o(n^2)，适合稠密图
2.打印最小生成树比较困难
3.需要构建图结构，如果是稠密图，建议使用邻接矩阵，稀疏图，使用邻接表

kruskal
1.以边为角度，复杂度为O（logn）,适合稀疏图
2.打印最小生成树方便
3.不需要构建图结构，构建一个边结构即可
4.需要借助并查集实现
```python
class Edge:
    def __init__(self,f,t,v):
        self.f = f
        self.t = t
        self.v = v
```
