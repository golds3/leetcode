1. 主对角线（↘）

主对角线的特征是：行号 - 列号相等。
由于 row - col 可能是负数（范围 [-n+1, n-1]），所以我们用 row - col + (n-1) 来把它映射成数组下标范围 [0, 2n-2]。

2. 副对角线（↙）

副对角线的特征是：行号 + 列号相等。
这个值天然是非负数，范围 [0, 2n-2]，直接就能当数组下标。

因此对角线数组可以用一个2n-1长度的数组表示
```python
        diag1 = [False] * (2 * n - 1)  # row - col 取值范围 [-n+1, n-1]，偏移 n-1
        diag2 = [False] * (2 * n - 1)  # row + col 取值范围 [0, 2n-2]
```
对于下标(i,j)判读的方式
```python
diag1[i - j + n - 1] # 主对角线
not diag2[i + j] # 反对角线
```
