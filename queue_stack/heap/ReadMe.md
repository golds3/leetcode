# 技巧
1. 堆是一个完全二叉树
2. 一般分为小顶堆和大顶堆
3. 小顶堆： 前k个最大元素 ---- （堆顶是最小的元素，如果新的元素比堆顶大，那么堆顶肯定不是那k个，被弹出，如果新的元素比堆顶小，那么新的元素肯定不是，堆化后弹出的就是他），如果用最大堆，那么堆的大小就需要为n，全部放入堆中再取前k个
4. 大顶堆 ： 1.前k个最小元素（原理如上） 2.区间中最大的元素
5. 对于python ，使用heapq包的api即可实现堆功能，如heappush、heappop，另外如果排序的元素不是元素本身，那么建议使用tuple放入堆，其中第一个元素为要排序的值
6. 如果要实现最大堆，只需要在heappush的时候插入-num 就可以
